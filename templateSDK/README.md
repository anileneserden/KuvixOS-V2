# Template SDK

Bu klasor, KEF SDK uzerinden yeni uygulama baslatmak icin tekrar kullanilabilir taslaklar icerir.

## Klasorler

- `console_app/`
  Temel bir console uygulamasi iskeleti.
- `window_app/`
  JSON layout kullanan temel bir window uygulamasi iskeleti.

## Onerilen Kullanim

Yeni bir uygulama acarken bu klasorlerden birini kopyalayip uygulama adina gore yeniden adlandirin.

Ornek:

```text
templateSDK/console_app   ->   apps/testApp1
templateSDK/window_app    ->   apps/myWindowApp
```

Bu dosyalar su an SDK yuzeyini gosteren taslaklardir. Henuz gercek `.kef` uretimi yapmazlar.
